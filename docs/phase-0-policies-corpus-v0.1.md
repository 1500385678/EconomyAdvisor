### POL-25 日本"住专"危机 + 1995《住専処理方策》6 行政策对照

- **发布机构**:大藏省(财务省前身) + 日本银行 + 7 家"住专"(住宅金融専門会社)
- **时间**:1995/12/22(《住専処理方策》正式发表)
- **核心条款**:7 家住宅金融専門会社(住专)累计 8 行业不良债权 6.41 万亿日元 → 由日本银行 + 农林系金融机构 + 母体银行三方共担 → 1996/3 全部住专完成清盘

- **市场反应**:1995/12/19 方案提前泄露 → 日经 225 单日 -5.6%(1990 以来最大跌幅之一)→ 1996 初母体银行股价反弹 +20% / 1996-1997 日本经济"失去的十年"正式开启
- **RAG 适用度**:**高** —— 房地产泡沫→银行不良→公共资金处置的**完整闭环**,与 2026 中国"地产新模式+地方化债"的政策组合形成 30 年最贴近的国际镜像

  | **触发因素** | 地产/股价泡沫破裂后 5 年累积不良 | 2021 三道红线后 5 年累积地产销售/投资双降 |
  | **处置工具** | 日本银行注资 + 母行共担 + 农系统转移 | 央行再贷款工具 + 国有 AMC 收储 + 白名单 |
  | **公共资金规模** | 6850 亿日元 ≈ GDP 0.14% | 8000 亿元保障性住房再贷款 ≈ GDP 0.06% |
  | **金融体系冲击** | 22 家母体行不良率 1996 升至 4.5% | 国有 AMC 不良率历史峰值 8-10% |
  | **后续路径** | 失去的十年(1996-2005 通缩 + 零利率) | 仍处调整初期,2026-2028 路径未定 |

  - **受益**:国有 AMC(信达/华融/长城/东方)+ 房地产服务(物业/中介)+ 基建(保障房建设)
  - **受损**:高杠杆民营房企 + 商业地产 REITs + 城商行地产敞口

### POL-26 香港 1997-2003 楼市危机 +《"八万五"建屋计划》从加码到撤销

- **发布机构**:香港特别行政区政府 + 房屋委员会(房委会) + 香港金融管理局(金管局)
- **时间**:1997/10 董建华首份《施政报告》提出 → 1998-2001 每年供应 8.5 万套公营+私营房屋 → 2002/11 董建华宣布"无限期搁置" → 2003/7 沙士(SARS)后启动"孙九招"救市(撤销"八万五"+暂停居屋+停卖地+减勾地)
- **核心条款**:1997 亚洲金融风暴冲击香港联系汇率 → 港元资产价格"脱钩"楼市 → 1997-2003 楼价累计下跌 65%(差饷物业估价署中原城市指数 -65%)→ 负资产宗数 2003/6 峰值 105,697 宗(占按揭贷款 ~22%)→ 董建华"八万五"目标 70 万套/10 年(年均 7 万套,加 1999 修订 8.5 万套),导致供应端"放量"叠加需求端"消失" → 2002/11 政策转弯
- **时代背景**:1984《中英联合声明》"新界"批地设限 → 1990 年代港英政府"玫瑰园计划"基建扩张(新机场+西九龙填海+青衣北)→ 1997 回归 + 亚洲金融风暴 + 索罗斯狙击港元 + 联系汇率 8.75 守稳 + 1998 港府入市(盈富基金前身)+ 2001 互联网泡沫 + 2003 SARS
- **政策意图(前)**:回归后"居者有其屋"承诺 + 10 年 70 万套公私营房屋(每年 8.5 万套)目标 + 1997 政策意图对冲高房价(港岛 1997 中原 CCI 100 → 100)
- **政策意图(后)**:2002/11 "八万五"暂停 + 2003/7 "孙九招"——撤"勾地"+停"居屋"+停"卖地"+减建屋量+放宽按揭成数(LTV 上调 +10pct)+暂停公屋富户政策
- **市场反应**:1997/10 政策加码 → 1998-2001 楼价继续下跌 45%(八万五雪上加霜)→ 2002/11 暂停 → 2003/7 救市"孙九招" → 2003/8 楼价见底回升 +5% → 2004-2007 楼价反弹 +70% → 2007 港岛楼价超越 1997 高位
- **RAG 适用度**:**高** —— 亚洲金融危机 → 楼市危机 → 政策加码反而加速下行 → 政策转弯"四步走"的**完整逆向调控**案例,与 2026 中国"地产新模式(需求端发力 vs 供给端收缩)"形成 20 年最贴近的国际镜像
- **5 大制度维度 × POL-26 对照**:
  | 维度 | 香港 1997-2003 楼市危机 | 中国 2026 地产新模式 |
  |---|---|---|
  | **触发因素** | 亚洲金融风暴 + 港元利率跟随美元升至 9.5% | 2021 三道红线 + 2022-2025 销售/投资累计 -38%/-21% |
  | **处置工具** | "八万五"加码 → 救市"孙九招"(撤+停+减+放) | 央行 8000 亿保障房再贷款 + 收购存量房 + 白名单 |
  | **公共资金规模** | 房屋委员会居屋(无注资)+ 2003 暂停卖地损失 ~200 亿港元 | 央行 8000 亿 PSL-style 工具 ≈ GDP 0.06% |
  | **金融体系冲击** | 负资产 2003/6 峰值 105,697 宗 / 占按揭 ~22% | 个贷不良率 2025 末 ~0.6%, 房贷 ABS 不良 ~1.2% |
  | **后续路径** | 2004-2007 反弹 +70% → 2008 金融危机再跌 → 2010-2018 长期上行 | 仍处调整初期,2026-2028 路径未定 |
- **受益/受损板块(国际经验,中国对应)**:
  - **受益(救市)**:香港模式"孙九招"对应中国 2025-2026 "白名单"+ 收购存量房 + LTV 调整 —— **地产服务(物管/中介)+ 央企开发商(中海/华润/招商蛇口)+ 基建(保障房建设链)**
  - **受损(去库存)**:香港"八万五"期(1997-2001)对应中国 2021-2024 —— **高杠杆民营房企(碧桂园/融创/恒大)+ 商业地产 REITs + 城商行地产敞口**
- **一手源**:香港房委会历年《房屋报告》+ 1997《施政报告》第 7 章"房屋政策"+ 2003/7 房屋及规划地政局《稳定楼市措施》("孙九招")+ 差饷物业估价署《香港物业报告》+ HKMA《金融管理局季报》2003 Q2
- **日报片段**:本文件首次落地,无日报片段;后续 9-10 日报将引用作为"亚洲金融风暴后地产政策史"对照

### POL-27 美国 2007-2010 次贷危机 +《TARP》7000 亿 + HAMP 房贷修改

- **发布机构**:美国财政部( Treasury) + 美联储(Fed) + 联邦存款保险公司(FDIC) + 联邦住房金融局(FHFA,2008/7 接管 Fannie Mae / Freddie Mac) + 联邦住房管理局(FHA,HAMP 主导) + 司法部(司法救助配套)
- **时间**:2007/4 New Century Financial 破产 → 2007/6 贝尔斯登旗下两只对冲基金爆仓 → 2008/3 贝尔斯登 290 亿美元贱卖摩根大通 → 2008/9/15 雷曼破产(158 年老店)→ 2008/9/16 AIG 850 亿美元国有化 → 2008/10/3 TARP 7000 亿签署 → 2008/11/25 Fed 启动 QE1 → 2009/2/18 ARRA 7870 亿刺激 + HAMP 立法 → 2009/3 银行压力测试(SCAP)→ 2009/6 银行回购 TARP 优先股启动 → 2010/3 HAMP 永久延期 + 2010/7 Dodd-Frank 2300 页金融监管改革
- **核心条款**:
  - **TARP**(Troubled Asset Relief Program,2008/10/3 签署):7000 亿美元授权(后缩至 4750 亿实际使用),财政部向 700+ 银行注资优先股 + 认股权证,**AIG 救助 1823 亿 + 花旗 450 亿 + 美银 450 亿 + 富国 250 亿 + 摩根大通 250 亿**(五大占 67%)+ 汽车业 800 亿(克莱斯勒+通用)→ 实际**净收益 510 亿美元**(财政部 2014 年宣布完全退出,2020 年 TARP 整体实现 333 亿净收益)
  - **HAMP**(Home Affordable Modification Program,2009/2/18 ARRA 立法):房贷修改 5 年试点,**目标 300-400 万家庭**(实际修改 ~180 万,达成率 50%)+ 房贷余额降至 31% 收入比 + 利率最低降至 2% + 5 年期阶梯式还本
  - **HARP**(Home Affordable Refinance Program):Fannie / Freddie 抵押贷款再融资,**目标 400-500 万户**—— 实际 ~330 万户(达成率 70%)
  - **FHFA 接管**两房(2008/9/7 保守监管,2008/9/14 强制接管):5.2 万亿美元 MBS 余额 → 财政部 1916 亿美元优先股注资 + 信用证兜底
  - **FDIC TLGP**(Temporary Liquidity Guarantee Program,2008/10/14 启动):银行债务全额担保,有效防止银行间市场冻结
  - **Fed 紧急贷款**:TAF(2007/12 启动,2008/3 扩展)2000 亿 + TSLF(2008/3)2000 亿 + PDCF(2008/3,投行)2900 亿 + CPFF(2008/10,商业票据)1.7 万亿
  - **QE1**(2008/11/25 - 2010/3):1.725 万亿美元 MBS + 1750 亿国债
- **时代背景**:**次贷产品(Subprime MBS / CDO / CDS)** 2003-2006 高速扩张(2006 年次贷发放 6000 亿美元,占总按揭 23%)+ 房价 2000-2006 累计上涨 124%(Case-Shiller 20 城)→ 2006/6 房价见顶 → 2007/4 房价见顶反转 → 2008/9-10 雷曼/AIG/华盛顿互惠银行三家巨型金融机构 60 天内集中破产(史上仅见)→ 2008 Q4 美国 GDP 环比折年 -8.4% + 失业率 2007/4 的 4.5% → 2009/10 峰值 10.0% + 道指 2009/3 跌至 6547 点(从 2007/10 14279 跌 54%)
- **政策意图(前)**:1999 金融现代化法案(GLBA)废除格拉斯-斯蒂格尔 → 2004 SEC 净资本规则放松(5:1 杠杆放至 12:1-40:1)→ 2005 联邦预算法案剥夺 OFHEO 对两房的监管权 → 影子银行体系(投资银行 + SPV + SIV)非杠杆化运营,系统性风险无人监控
- **政策意图(后)**:TARP 救"系统重要性金融机构"(SIFI)免于"太大不能倒"传染 + HAMP 救"普通家庭"免于法拍 + 两房国有化"先稳定金融体系再说" + Fed 量化宽松替代零利率下限失效的传统货币政策 + Dodd-Frank 重建"系统性风险监管 + 消费者保护 + 衍生品场外清算"三大支柱 + 2010/7 巴塞尔协议 III(2013 起分阶段实施)
- **市场反应**:
  - **救市信号**:2008/10/13 TARP 首期 1250 亿注资 9 大行 → 银行股 +20% 反弹 → 2008/10/28 标普 500 跌至 849(13 年新低)→ 2009/3/9 标普 676(12 年新低,QE1 启动后回升)→ 2009/3 低点反弹至 2010/4 1218(+80%)
  - **就业反弹**:2009/10 失业率 10.0% 峰值 → 2015/5 5.5%(奥巴马第二任中期)→ 2019/9 3.5%(历史低位)
  - **房价反弹**:Case-Shiller 20 城 2012/3 底部 134 → 2022/6 峰值 313(+133%)
  - **道指反弹**:2009/3 6547 → 2018/1 26616(+306%,近 10 年长牛)
- **RAG 适用度**:**高** —— 金融危机 → 公共资金处置 + 家庭部门救助 + 量化宽松 + 金融监管改革 4 工具**全谱系案例**,与 2026 中国"地产新模式 + 央行 PSL 工具 + 收购存量房"形成**完整对照**;RAG 适用度高于 POL-25(单点处置)与 POL-26(政策反复),POL-27 是"系统性金融危机 → 全谱系救市 → 长期监管改革"的**教科书级**国际案例
- **5 大制度维度 × POL-27 对照**:
  | 维度 | 美国 2007-2010 次贷危机 + TARP / HAMP | 中国 2026 地产新模式 |
  |---|---|---|
  | **触发因素** | 次贷 MBS / CDO 2003-2006 高速扩张 + 房价 2006/6 见顶 + 影子银行体系无监管 | 2021 三道红线 + 2022-2025 销售/投资累计 -38%/-21% + 房价 2021/9 见顶 + 房企美元债违约 |
