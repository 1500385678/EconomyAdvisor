**分类口径**

- **指标**:可数值化、可时序化、可查询的宏观/市场数据(GDP / CPI / 利率 / 汇率 / 收益率等)
- **政策**:政府/监管/央行的文件、规则、办法、讲话、窗口指导等定性条款
- **事件**:有具体时间点的市场/经济/国际事件,以及可对照的"历史剧本"
- **资产**:可交易标的(股 / 债 / 商品 / 外汇)的当日波动 + 归因 + 历史相似情境
