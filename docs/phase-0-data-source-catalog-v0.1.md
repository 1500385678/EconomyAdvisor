# 2026-08-25 · 5 大官方宏观数据源接入清单 v0.1

> Phase 0 §5-2 前置调研 · EconomyAdvisor
> 对应 `项目开发计划.md §5` 第 2 条:`跑通 5 大免费宏观数据源(国家统计局/央行/财政部/海关/商务部)的 API 或爬虫`
> 目的:在动手写爬虫前,先把 5 大源**是否官方 API / 字段范围 / 更新频率 / 接入难度**摸清楚,作为下周 §5-2 真正接入的施工图

---

## §0 调研范围

- **目标源**:国家统计局 · 中国人民银行 · 财政部 · 海关总署 · 商务部
- **优先级判断口径**:
  - **P0(MVP 必备)**:覆盖 GDP / CPI / PMI / M2 / 社融 / 利率 / 汇率 7 个核心指标中至少 4 个
  - **P1(第二批)**:覆盖外储 / 财政收支 / 进出口 / 消费 / 投资 / 工业利润
  - **P2(扩展)**:行业级 / 区域级 / 历史回溯

## §1 国家统计局(NBS) — P0

| 维度 | 内容 |
|---|---|
| 官网 | https://www.stats.gov.cn |
| 数据门户 | https://data.stats.gov.cn(数据查询主入口) |
| API 形态 | **无官方公开 API**;`data.stats.gov.cn` 提供网页查询 + JSON 响应(浏览器 XHR 可抓) |
| 覆盖指标 | GDP · CPI · PPI · 工业增加值 · 固投 · 社零 · 失业率 · 人口(年度/季度/月度) |
| 更新频率 | 月度指标次月 10-15 日发布;季度 GDP 次季度首月 15-20 日;年度 1 月底 |
| 接入方式 | 浏览器开发者工具抓 `data.stats.gov.cn/easyquery.htm` 的 XHR,或自写 HTML 解析器 |
| 接入难度 | ★★☆☆☆(JSON 易抓但字段映射需要适配) |
| 风险 | 网页结构变更风险;无 SLA;高频抓取可能触发反爬 |
| 替代源 | akshare(已封装) / tushare 公益版(申请后免费) |
| MVP 建议 | 走 akshare 优先,自抓降级 |

## §2 中国人民银行(PBOC) — P0

| 维度 | 内容 |
|---|---|
| 官网 | http://www.pbc.gov.cn |
| 数据栏目 | 调查统计司 · 货币政策司 · 公开市场操作公告 |
| API 形态 | **无统一 API**;公告页 + 表格 + PDF 三种形式;**部分时间序列提供 CSV 下载**(调查统计司栏目) |
| 覆盖指标 | M0/M1/M2 · 社融 · 贷款 · 外汇储备 · 公开市场操作(逆回购/MLF/SLF/PSL) · 银行家/企业家/储户问卷 |
| 更新频率 | M2/社融月度 10-15 日;公开市场操作每日;问卷季度 |
| 接入方式 | 公告页 HTML 解析(每日 OMO)+ CSV 下载(社融/M2/外储)+ PDF 解析(货币政策报告) |
| 接入难度 | ★★★☆☆(公告页结构稳定但需逐栏目适配) |
| 风险 | 央行栏目改版频率低,稳定;PDF 解析需要 OCR fallback |
| 替代源 | akshare(`macro_china_*` 系列) / Wind |
| MVP 建议 | 公开市场操作用 HTML 解析(每日 17:00 抓一次);M2/社融用 akshare |

## §3 财政部(MOF) — P1

| 维度 | 内容 |
|---|---|
| 官网 | http://www.mof.gov.cn |
| 数据栏目 | 国库司 · 预算司 · 税政司 |
| API 形态 | **无 API**;**月度财政收支数据发布为新闻稿 + 附表**(HTML 表格) |
| 覆盖指标 | 一般公共预算收入/支出 · 政府性基金 · 国有资本经营 · 中央对地方转移支付 · 国债发行 |
| 更新频率 | 月度收支次月 15-20 日;国债发行日度 |
| 接入方式 | 新闻稿 HTML 解析(抓附表) + 国债发行公告 PDF/HTML 解析 |
| 接入难度 | ★★★☆☆(HTML 表格规整,但栏目分散) |
| 风险 | 栏目分散,需按子栏目分别抓 |
| 替代源 | 财政数据由统计局间接公布(社零/固投口径),MVP 阶段可降级 |
| MVP 建议 | 第一版只抓月度收支总表(1 个 URL),不做国库券明细 |

## §4 海关总署(GACC) — P1

| 维度 | 内容 |
|---|---|
| 官网 | http://www.customs.gov.cn |
| 数据栏目 | 统计数据 · 统计月报 |
| API 形态 | **无 API**;**月度统计月报提供 HTML 表格 + PDF**(规整度好) |
| 覆盖指标 | 进出口总额(美元/人民币) · 贸易差额 · 分国别 · 分商品(HS 编码) · 海关特殊监管 |
| 更新频率 | 月度数据次月 12-15 日发布 |
| 接入方式 | 统计月报 HTML 表格解析(主要数据) + PDF 解析(分商品明细) |
| 接入难度 | ★★☆☆☆(表格规整,字段清晰) |
| 风险 | 反爬轻度,IP 限频需控制 |
| 替代源 | akshare(`macro_china_hk_trade`) / 商务部转引 |
| MVP 建议 | 走海关 HTML 表格解析,只取进出口总额/差额/分国别前 10 |

## §5 商务部(MOFCOM) — P2

| 维度 | 内容 |
|---|---|
| 官网 | http://www.mofcom.gov.cn |
| 数据栏目 | 运行监测 · 外贸司 · 投资促进事务局 |
| API 形态 | **无 API**;数据散落在新闻稿和子栏目,需手工聚合 |
| 覆盖指标 | 社会消费品零售总额(部分) · FDI · 实际使用外资 · 对外直接投资 · 重要商品流通(成品油/汽车/家电) |
| 更新频率 | 月度/季度混发,无固定日历 |
| 接入方式 | 栏目订阅 + 新闻稿聚合,需定制爬虫 |
| 接入难度 | ★★★★☆(数据散,口径不一) |
| 风险 | 栏目改版频繁,无 SLA |
| 替代源 | 社零口径优先走统计局,商务部数据只做补全 |
| MVP 建议 | **MVP 阶段跳过**,第二批补 FDI/对外投资 |

## §6 综合判断

### 6.1 MVP 阶段数据源优先级(2026-10-31 前)

| 优先级 | 源 | 接入方式 | 覆盖核心指标 | 难度 |
|---|---|---|---|---|
| **P0** | NBS | akshare + 自抓降级 | GDP / CPI / PPI / 工业 / 社零 | ★★ |
| **P0** | PBOC | akshare(M2/社融/外储)+ HTML 解析(OMO) | M2 / 社融 / OMO | ★★★ |
| P1 | GACC | HTML 表格解析 | 进出口 / 贸易差额 | ★★ |
| P1 | MOF | HTML 表格解析(收支总表) | 财政收支 | ★★★ |
| P2 | MOFCOM | 暂跳过 | — | ★★★★ |

### 6.2 统一接入层建议

```
[NBS API]  ┐
[PBOC API] ├──> Adapters(标准化层)──> EconomyIngest(table)──> ClickHouse
[GACC API] │       • unit 标准化(元/万元/亿美元)
[MOF API]  ┘       • freq 标准化(日/月/季/年)
                   • 字段命名统一(snake_case + 指标代码)
                   • 时间戳统一(ISO 8601 + 北京时)
```

### 6.3 下周(§5-2 实际跑通)任务分解

1. **Day 1**:akshare 环境验证 + 5 个核心指标(`macro_china_gdp` / `macro_china_cpi` / `macro_china_pmi` / `macro_china_m2` / `macro_china_shrzgm`)跑通
2. **Day 2**:PBOC 公开市场操作公告页 HTML 解析(每日 cron 抓取)
3. **Day 3**:NBS 直抓降级路径验证(data.stats.gov.cn XHR)
4. **Day 4**:EconomyIngest 表 schema 落 SQLite
5. **Day 5**:5 源 → EconomyIngest → ClickHouse 端到端 demo
